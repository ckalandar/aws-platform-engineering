Complete Rebuild Steps

Phase 0 — Prerequisites

Ensure [PERSON_NAME] is running on port 4566 — the Terraform setup uses it for AWS API emulation (EKS, ECR, S3, DynamoDB, etc.):

! docker ps | grep floci   # should show [IP_ADDRESS]:4566->4566

If it's not running, start it:
* IMPORTANT: use floci/floci (not localstack/localstack:3 which lacks EKS/ECR support)
docker rm -f localstack floci 2>/dev/null
docker run -d --name floci -p 4566:4566 -v /var/run/docker.sock:/var/run/docker.sock -v floci-data:/var/lib/localstack floci/floci:latest

Verify it is running:
docker ps | grep floci
aws eks list-clusters --endpoint-url http://localhost:4566   # should return {"clusters":[]}

Actions that must be taken **after** `terraform apply` completes during a fresh build.

## 1. Delete ALB webhooks (blocks Service + Ingress creation)

The AWS Load Balancer Controller webhooks fail in local k3s (TLS cert error).

```bash
kubectl delete mutatingwebhookconfiguration aws-load-balancer-webhook
kubectl delete validatingwebhookconfiguration aws-load-balancer-webhook
```

Then **sync the springboot ArgoCD app**:
```bash
kubectl patch application springboot -n argocd --type merge \
  -p '{"operation":{"sync":{"syncOptions":["CreateNamespace=true"],"prune":true}}}'
```

## 2. Node-exporter mount propagation

If the node-exporter pod is stuck with `CreateContainerError` and error `"path "/" is mounted on "/" but it is not a shared or slave mount"`:

```bash
kubectl patch daemonset -n monitoring monitoring-prometheus-node-exporter --type=json \
  -p='[{"op": "replace", "path": "/spec/template/spec/containers/0/volumeMounts/2/mountPropagation", "value": "None"}]'
```

This will trigger a rolling restart; the new pod should start running.

## 3. Verify registries.yaml inside k3s

If springboot pods have `ImagePullBackOff` with `"http: server gave HTTP response to HTTPS client"`:

```bash
# Check if the file has the right content
docker exec floci-eks-kk-platform-dev grep "host.docker.internal" /etc/rancher/k3s/registries.yaml

# If NOT found, copy it in and restart
docker cp infrastructure/floci/registries.yaml floci-eks-kk-platform-dev:/etc/rancher/k3s/registries.yaml
docker restart floci-eks-kk-platform-dev
# Wait ~20s for node to come back
```

The script should handle this automatically, but double-check if it doesn't.

kubectl get svc -n springboot -o yaml | grep -A2 "name: http"
